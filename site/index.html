Under the surface

A modern web.
An honest preview.

The Chromium source build embeds the real Chromium Embedded Framework: native rendering, JavaScript modules, and responsive CSS. New Chromium builds select that engine by default; existing preferences stay yours.

The current v0.1.0 download uses WebKit, not Chromium. Chromium remains experimental: its pinned CEF release trails Chrome stable, and Developer ID signing and notarization are not complete. This is not a hardened replacement for your everyday browser.

Install the developer preview

Homebrew installs the published, universal WebKit preview for Apple Silicon and Intel.

brew install --cask mrashrhodes/cairn/cairn

Ad-hoc signed, not Apple-notarized. macOS may block it. Do not disable system security protections to run it.

Build the Chromium workspace

For developers with Swift 6 and Apple's Command Line Tools. Download and build the pinned CEF dependency first; the guide covers both supported architectures.

git clone https://github.com/MrAshRhodes/cairn.git
cd cairn
python3 engine/tool.py fetch
python3 engine/tool.py build
make app
