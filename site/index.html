CURRENT DOWNLOADWebKit v0.1.0
CHROMIUM BUILDExperimental

The published preview uses WebKit. Chromium remains experimental: its pinned CEF release trails Chrome stable, and Developer ID signing and notarization are not complete. It is not a hardened replacement for your everyday browser.

AFOR YOUR MAC

Try the developer preview

Homebrew installs the published universal WebKit preview for Apple Silicon and Intel.

brew install --cask mrashrhodes/cairn/cairn

Ad-hoc signed, not Apple-notarized. macOS may block it. Do not disable system security protections to run it.

BFOR BUILDERS

Build the Chromium workspace

For developers with Swift 6 and Apple’s Command Line Tools. The guide covers both supported architectures.

git clone https://github.com/MrAshRhodes/cairn.git
cd cairn
python3 engine/tool.py fetch
python3 engine/tool.py build
make app
